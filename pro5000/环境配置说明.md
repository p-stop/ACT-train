# pro5000 上的 ACT 训练环境配置说明

- 日期：2026-11-09
- 机器：pro5000（8 × RTX PRO 5000 72GB Blackwell，256 核，743 GB 内存）
- 所有东西都在 **`<PRO5000_ACT_DIR>`** 下。根分区 `/` 只剩约 17 GB，所以没有往家目录里放大文件；家目录里只多了 uv 这个工具（见第 2 节）。
- 本机副本：[pro5000_ACT配置说明_20261109.md](<WORK_DIR>/pro5000_ACT配置说明_20261109.md)；pro5000 上的副本：`<PRO5000_ACT_DIR>/pro5000_ACT配置说明.md`

## 2. Python 环境

| 项目 | 内容 |
|---|---|
| uv | `pip3 install --user uv`（腾讯 PyPI 镜像），在 `~/.local/bin/uv`；`uv python install` 还在 `~/.local/bin/` 放了一个 `python3.12` 快捷方式 |

| 虚拟环境 | `<PRO5000_ACT_DIR>/.venv`，安装 `lerobot[training]==0.6.1`，用 `setup_logs/constraints_from_wxr5.txt` 把所有依赖锁到和 wxr5 相同的版本 |
| 关键版本 | torch 2.11.0+cu130、torchvision 0.26.0、torchcodec 0.11.1、av 15.1.0、huggingface_hub 1.33.0、wandb 0.27.2 |

使用方法：

```bash
source <PRO5000_ACT_DIR>/.venv/bin/activate      # 之后 lerobot-train 等命令可直接用
# 这个环境里没有 pip，装包用 uv：
export PATH=$HOME/.local/bin:$PATH
uv pip install --python <PRO5000_ACT_DIR>/.venv/bin/python -i https://mirrors.tencent.com/pypi/simple <包名>
```

和 wxr5 的环境相比只少一个 `grpcio`（远程推理服务端才用，训练用不到）。要在 pro5000 上跑推理服务端，用上面的命令补装 `grpcio`。

## 3. 网络情况（决定了上面的装法）

| 目标 | pro5000 上的情况 |
|---|---|
| 腾讯 PyPI 镜像 `mirrors.tencent.com/pypi/simple` | 很快，所有 Python 包都从这里装 |
| 官方 PyPI、download.pytorch.org | 只有 10–50 KB/s |
| GitHub | github.com 连不上，codeload 约 12 KB/s |
| huggingface.co | 连不上（超时） |
| hf-mirror.com | 能连，但**没有用**：下载私有数据集要把 HF token 交给这个第三方镜像，私有数据也可能被它缓存 |
| api.wandb.ai | 能连 |

所以 pro5000 上没有登录 Hugging Face，训练时设了 `HF_HUB_OFFLINE=1`，数据集全部从本地读。

## 4. 数据集是怎么来的

1. 两个增强数据集已从目标服务器推到 HF **私有**仓库 `<HF_USER>/01_ACT_fused`、`<HF_USER>/01_ACT_mixR`（打了 lerobot 需要的 `v3.0` 标签，各附一份 README 说明来源）。
2. pro5000 连不上 HF，所以没有从 HF 下载，而是：
   - 原始数据集 `01_ACT` 从 wxr5 经 SSH 直传（764 MB，md5 和原文件一致）；
   - 用和目标服务器上完全相同的脚本、相同的随机种子，在 pro5000 上重新生成两个数据集（`tools/aug01/rebuild_on_pro5000.sh`）。
3. 与推到 HF 的版本比对：

| | fused | mixR |
|---|---|---|
| 逐条配对清单 `meta/aug_manifest.json`（含分界线、两臂距离） | 完全相同 | 完全相同 |
| 关节状态和动作（逐帧数据摘要） | 完全相同 | 完全相同 |
| 解码后的画面（抽样 108 帧，三路相机） | 逐像素相同 | 待补（比对时到目标服务器的通路断了） |

视频文件本身的 md5 不同，是编码器在不同 CPU 上的比特级差异，画面内容一致。

## 5. 三个模型

超参数全部和之前 wxr5 上的 `act_01_ACT_300k` 一致，只有数据不同：

`--policy.type=act --steps=300000 --batch_size=8 --seed=1000 --save_freq=20000 --log_freq=200`，学习率 1e-5（ACT 默认），图像增强关闭，wandb 离线记录。唯一改动是 `--num_workers=8`（原来是 4，只影响数据加载速度）。

| 模型 | 数据 | 回合 | 帧数 | 显卡 | tmux 会话 | 开始时间 |
|---|---|---|---|---|---|---|
| ACT_bi | `01_ACT_fused` 去掉您标记不要的 7、10、11、15、25、44、45 | 45 条 | 28127 | 1 号 | `ACT_bi` | 11-09 22:12 |
| ACT_mix | `01_ACT_mixR` 中用固定种子随机抽 52 条 | 52 条 | 62165 | 1 号 | `ACT_mix` | 11-09 22:47 |
| ACT_fmix | `01_ACT_mixR` 全部 | 156 条 | 183567 | 4 号 | `ACT_fmix` | 11-09 22:47 |

- 回合列表在 `tools/episode_lists.json`。ACT_mix 用 `numpy.random.default_rng(0).choice(156, 52, replace=False)` 抽取，抽中的是：0, 1, 3, 4, 8, 11, 12, 18, 19, 23, 29, 33, 34, 39, 42, 50, 54, 58, 59, 60, 66, 67, 68, 71, 72, 74, 75, 76, 79, 85, 87, 89, 92, 94, 97, 98, 100, 101, 102, 105, 111, 114, 115, 118, 119, 123, 131, 142, 144, 145, 146, 148。mixR 里第 3k 条是原始第 k 条，3k+1、3k+2 是它的两个混合副本，所以这 52 条里有 19 条原始示教、33 条混合副本。
- 显卡：开工前 1 号和 4 号卡完全空闲（0 MiB），其余各卡被别人占着；按您的要求最多用 2 张卡。1 号卡上同时跑两个模型，速度各约 5.6 步/秒；4 号卡上单独跑一个，约 11.7 步/秒。
- 预计用时：ACT_fmix 约 7 小时；ACT_bi、ACT_mix 约 13–15 小时。ACT_fmix 跑完以后 4 号卡空出来，1 号卡上的两个会自然变快一点（它们是数据加载和 GPU 共同受限）。
- 显存：每个模型约 7 GB。

## 6. 查看和调整

```bash
tmux ls                                   # 三个会话 ACT_bi / ACT_mix / ACT_fmix
tmux attach -t ACT_bi                     # 看实时输出；离开按 Ctrl+b 再按 d（不要按 Ctrl+c，会停止训练）
tail -c 2000 <PRO5000_ACT_DIR>/outputs/logs/ACT_bi.log | tr '\r' '\n' | tail -3   # 不进 tmux 看进度
grep -o "loss:[0-9.]*" <PRO5000_ACT_DIR>/outputs/logs/ACT_bi.log | tail          # 损失
ls <PRO5000_ACT_DIR>/outputs/train/ACT_bi/checkpoints/                             # 每 2 万步一个检查点
nvidia-smi                                # 显卡占用
```

- **启动或重启一个模型**：`cd <PRO5000_ACT_DIR> && tmux new -d -s <模型名> "tools/train_act.sh <模型名> <卡号> 2>&1 | tee outputs/logs/<模型名>.log"`。输出目录已存在时 lerobot 会报错：重新训练先改名或删掉 `outputs/train/<模型名>`。
- **断点续训**（比如进程被停了）：
  `CUDA_VISIBLE_DEVICES=<卡号> HF_HUB_OFFLINE=1 .venv/bin/lerobot-train --resume=true --config_path=outputs/train/<模型名>/checkpoints/last/pretrained_model/train_config.json`
- **换卡、改步数、改批大小、打开图像增强**：改 `tools/train_act.sh` 里 `ARGS=(...)` 那几行，例如加 `--dataset.image_transforms.enable=true`、改 `--batch_size=16`。
- **wandb**：现在是离线记录（`--wandb.mode=offline`），没有在 pro5000 上登录 wandb。想上传到网页：在 pro5000 上 `source .venv/bin/activate && wandb login`，然后 `wandb sync outputs/wandb_dirs/ACT_bi/wandb/offline-run-*`（pro5000 能连 api.wandb.ai）。
- **重新生成数据集**（比如标了分界线以后）：改好 `tools/aug01/rebuild_on_pro5000.sh` 里的 `build.py` 参数（标注文件用 `--seams`），再运行它。它会覆盖 `datasets/01_ACT_fused`、`datasets/01_ACT_mixR`，正在训练时不要运行。

## 7. 占用和清理

| 内容 | 大小 | 说明 |
|---|---|---|
| `.venv` + `python` | 约 5.5 GB | 训练环境 |
| `datasets/` | 约 3.7 GB | 原始 + 两个增强数据集 + 中间结果（`aug_work_01` 可删） |
| `outputs/train/*` | 每个模型 15 × 592 MB ≈ 9 GB | 每 2 万步一个检查点（含优化器状态）；不需要的中间检查点可以删 |
| `.uv_cache/` | 5.3 GB | 安装包缓存，可删（以后再装包会重新下载） |
| `~/.local/bin/uv`、`~/.local/bin/python3.12` | 很小 | 不用了可以 `pip3 uninstall uv` 并删掉这个快捷方式 |

- `/data1` 是多人共用的盘，`/data1/<WXR5_USER>` 现在的权限是 775，别的账号能读到里面的数据。如果不希望别人看到，可以 `chmod 750 /data1/<WXR5_USER>`。
- 整个删除：`rm -rf <PRO5000_ACT_DIR>`（先 `tmux kill-session -t <模型名>` 停掉训练）。
